# Scratch AI detector
Detects AI generated Scratch projects (Work in progress)

## Usage
Just run main.py however you like, you don't need to install anything else other than Python.

When running the program you'll get prompted to select a project. The numbered options are selected from the samples directory. You can put your sb3 file there, or you can enter a project ID and wait for the json file to download. There's no error handling yet so if the project is unshared the program will crash.

# Detection methods
## Variable IDS
Inside of the project.json file, each variable in a Scratch project is stored with a variable ID that holds both the variable name and its value. We explain each parameter in the detection below:

### Scratch generated
Normally, the Scratch editor generates 20 character long string made up from a specific list random characters. It is possible to check if variables were made with the Scratch editor by checking if the variable ID doesn't have any characters not in the list and the variable ID is not 20 characters long.

### Code generated
These are variable IDs that roughly match the variable name. This is checked by removing all symbols in both the variable name and ID and comparing both. This means that for example, "Very! cool_variable58" becomes "verycoolvariable58" for the check. If both match, then it means that it could be possible for the project.json to have been generated by a program other than Scratch, such as one of the many text-to-scratch compilers out there, or AI. It doesn't confirm AI use by itself though.

### Numeric generated
These are simply variables that contain a number. Sometimes you'll find variables that are named v1, v2, v3, etc. or have similar numerical names. These usually show up in AI generated projects, although not always. It's still plausible for these to have been generated by a program

### Other
Variables that don't fit any of the previous criteria, or are numeric generated, get added to this counter.
